## ✨ Features

| | Feature | What it does |
| :--: | :-- | :-- |
| 🪪 | **Live Profile** | Avatar, handle & follower count appear **as you paste** — no page reload, no guessing. |
| 🖼️ | **Multi-Select Carousel** | Carousel images render in a clean grid — **pick any**, download the whole batch at once. |
| 🎵 | **MP4 → MP3** | **FFmpeg in-browser**. Choose your bitrate from **96 → 320 kbps** and rip the audio locally. |
| 🔊 | **Real Audio** | Video previews **play with sound** — no more silent reels. |
| 🎚️ | **Quality Picker** | Pick the resolution / bitrate you actually want before you hit download. |
| 🎨 | **Theme Gallery** | **33 built-in themes** + a full **custom color** picker. |
| 📱 | **Mobile First** | Responsive, touch-friendly, thumb-reachable controls. Works on any phone. |
| 🔒 | **Local & Private** | Everything runs client-side. No accounts, no uploads, no tracking. |

## 🚀 How It Works

```text
  ┌──────────────┐      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
  │  1. PASTE    │ ───▶ │  2. PREVIEW  │ ───▶ │  3. SELECT   │ ───▶ │  4. DOWNLOAD │
  │  the link    │      │  live profile│      │  quality /   │      │  MP4 · JPG   │
  │              │      │  + media     │      │  images      │      │  · MP3       │
  └──────────────┘      └──────────────┘      └──────────────┘      └──────────────┘
```

1. Paste an Instagram Reel / Post / Carousel URL.
2. Watch the avatar, handle & follower count load instantly alongside a media preview.
3. Choose — single video, a subset of carousel images, or audio-only with your bitrate.
4. Download — files are assembled in your browser. Nothing leaves your device.

🏁 Quick Start

```bash
# 1. Clone
git clone https://github.com/hexsleuth/HEXInsta-Downloader.git

# 2. Enter
cd HEXInsta-Downloader

# 3. Serve locally (any static server works)
npx serve .
#   or
python -m http.server 8080
```

Then open http://localhost:8080 and paste a link. That's it — no build step, no .env, no API keys.

🌐 Or just use the hosted version: hexsleuth.github.io/HEXInsta-Downloader
